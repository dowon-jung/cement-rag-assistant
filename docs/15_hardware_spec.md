### PostgreSQL

| 항목 | 최소 | 권장 | 비고 |
|------|------|------|------|
| CPU | 2코어 | 4코어 | |
| RAM | 4GB | 16GB | shared_buffers = RAM의 25% 권장 |
| 디스크 | 50GB SSD | 200GB SSD | ERP 2년치 + 캐시 영구화 |
| IOPS | 1,000 | 5,000 | 배치 수집 시 쓰기 집중 |

```
예상 데이터 크기:

- market_rates: 약 2,000행 → 소량
- 총합 여유 포함: ~50GB면 충분
```

### Redis

| 항목 | 최소 | 권장 | 비고 |
|------|------|------|------|
| CPU | 1코어 | 2코어 | 싱글 스레드 구조라 코어 수 영향 적음 |
| RAM | 2GB | 8GB | TTL 캐시 + 임베딩 캐시 포함 |
| 디스크 | 5GB | 20GB | AOF 영속화 옵션 사용 시 |

```
예상 메모리 사용:
- 환율/뉴스/날씨 캐시: ~100MB
- 임베딩 캐시 (768 dim float32 × 10,000건): ~30MB
- 검색 결과 캐시: ~200MB
- 총합: ~500MB → 2GB면 여유 충분
```

### Qdrant

| 항목 | 최소 | 권장 | 비고 |
|------|------|------|------|
| CPU | 2코어 | 8코어 | 벡터 검색 병렬화 |
| RAM | 8GB | 32GB | 인덱스 메모리 적재 권장 |
| 디스크 | 50GB SSD | 200GB SSD | 벡터 + payload 저장 |

```
예상 벡터 크기:
- 768 dim × float32 = 3KB/벡터
- 규제 문서 500청크: ~1.5MB
- 유연탄 CSV 200청크: ~0.6MB
- 매뉴얼/품질 기준 1,000청크: ~3MB
- 총 벡터: ~2,000개 → 약 10MB
→ 초기에는 매우 소량, RAM 8GB면 충분
→ 문서 추가 시 선형 증가
```

### LLM 서빙 — Ollama (CPU 전용)

CPU만으로 구동 가능하지만 응답 속도가 느림.

| 모델 | RAM 요구량 | 응답 속도 (CPU) | 적합한 상황 |
|------|-----------|-----------------|-------------|
| Gemma2:2b | 4GB | ~5 tok/s | 테스트, 데모 |
| Gemma2:9b | 16GB | ~2 tok/s | 소규모 운영 |
| Gemma2:27b | 48GB | ~0.5 tok/s | 고품질, 저속 허용 |

```
권장 최소 사양 (Ollama CPU):
- CPU: 8코어 이상 (코어 수가 속도에 직결)
- RAM: 32GB (Gemma2:9b 기준 여유 포함)
- 디스크: 30GB (모델 파일)
```

---

### LLM 서빙 — vLLM (GPU 필수)

| GPU | VRAM | 구동 가능 모델 | 처리량 (TPS) |
|-----|------|----------------|--------------|
| RTX 3090 | 24GB | Gemma2:9b | ~60 tok/s |
| RTX 4090 | 24GB | Gemma2:9b | ~100 tok/s |
| A100 40GB | 40GB | Gemma2:27b | ~80 tok/s |
| A100 80GB | 80GB | Gemma2:27b (FP16) | ~150 tok/s |

```
권장 최소 사양 (vLLM):
- GPU: RTX 3090 또는 동급 (VRAM 24GB)
- CPU: 8코어
- RAM: 32GB (GPU 외 시스템 메모리)
- 디스크: 50GB SSD
- CUDA: 12.1 이상
```

> GPU 서버가 없는 경우 RunPod, Lambda Labs 같은 클라우드 GPU 서비스를
> 시간 단위로 임대해 벤치마크 진행 가능 (약 $0.5~2/시간).

## 3. 전체 구성별 서버 스펙 추천

### 구성 A — 단일 서버 (에어갭, CPU 전용)

모든 서비스를 서버 한 대에 Docker Compose로 운영.

```
권장 사양:
- CPU: AMD EPYC or Intel Xeon, 32코어
- RAM: 128GB ECC
- 디스크: OS 500GB SSD + 데이터 2TB NVMe
- 네트워크: 1Gbps

예상 비용 (국내 서버 구매 기준):
- 신품 기준: 약 500만~800만원
- 중고 서버: 약 150만~300만원

LLM: Gemma2:9b (Ollama, CPU) → 응답 약 2 tok/s
→ 소규모 내부 서비스에 적합
```

---

### 구성 B — 2서버 분리 (에어갭, GPU 포함)

LLM 서버와 나머지 서비스 서버를 분리.

```
서버 1 — LLM 서빙 전용:
- CPU: 8코어
- RAM: 32GB
- GPU: RTX 4090 (24GB VRAM)
- 디스크: 500GB SSD
- 예상 비용: 약 250만원 (RTX 4090 기준)

서버 2 — 앱 + DB + Kafka:
- CPU: 16코어
- RAM: 64GB
- 디스크: 1TB NVMe
- 예상 비용: 약 150만~200만원

합산: 약 400만~500만원
LLM: Gemma2:9b (vLLM) → 응답 약 100 tok/s
→ 프로덕션 수준, 동시 사용자 10~20명 처리 가능
```

---

### 구성 C — AWS 클라우드 (인터넷 가능 환경)

```
권장 인스턴스:
- FastAPI: EC2 t3.large (2vCPU, 8GB) × 2~3대
- DB/Kafka: EC2 m5.xlarge (4vCPU, 16GB)
- LLM (Bedrock): 별도 인스턴스 불필요 (API 과금)
- LLM (vLLM): EC2 g5.2xlarge (8vCPU, 32GB, A10G 24GB)

월 예상 비용 (상시 운영 기준):
- FastAPI × 2: ~$140/월
- DB/Kafka: ~$150/월
- g5.2xlarge (LLM): ~$600/월
- 합산: 약 $900/월 (약 120만원)

Bedrock 사용 시:
- g5.2xlarge 불필요 → ~$300/월 (약 40만원)
  + Claude 토큰 비용 별도
```

## 4. LLM 선택별 하드웨어 요건 요약

```
보안 최우선 (완전 폐쇄망)
    │
    ├─ GPU 서버 보유? → Yes → vLLM + Gemma2:9b
    │                          CPU 32GB + GPU 24GB
    │
    └─ GPU 없음 → Ollama + Gemma2:9b (CPU)
                  CPU 32코어 + RAM 64GB
                  (응답 느리지만 동작은 가능)

보안 중간 (AWS 사용)
    └─ AWS Bedrock (Claude)
       별도 GPU 서버 불필요
       EC2 + VPC 엔드포인트 설정

보안 낮음 (인터넷 가능)
    └─ Anthropic API (Claude)
       별도 GPU 서버 불필요
       API 키만 있으면 어디서든 사용
```

## 5. 초기 도입 시나리오별 추천

### 시나리오 1 — 내부 PoC (개념 검증)

```
목적: 기능 동작 확인, 도입 가능성 검토
기간: 1~2개월

하드웨어:
- 기존 개발 PC 또는 사무용 서버 활용
- RAM 32GB 이상이면 충분
- LLM: Anthropic API (AIRGAP_MODE=false)

비용: 추가 하드웨어 비용 없음
      Anthropic API 사용료만 발생 (~$50~100/월 예상)
```

### 시나리오 2 — 사내 서비스 도입 (소규모)

```
목적: 실 사용자 대상 서비스 운영
대상: 동시 사용자 5~10명

하드웨어:
- 서버 1대 (RAM 64GB, CPU 16코어)
- LLM: Ollama + Gemma2:9b (CPU)
- AIRGAP_MODE: 상황에 따라 선택

예산: 약 200만~300만원 (서버 구매 기준)
```

### 시나리오 3 — 고객사 납품 (프로덕션)

```
목적: 고객사 폐쇄망 납품
대상: 동시 사용자 20~50명

하드웨어:
- 서버 2대 분리 구성 (구성 B)
- LLM: vLLM + Gemma2:9b (GPU)
- AIRGAP_MODE=true

예산: 약 400만~500만원
      + Harbor 서버 1대 (기존 서버 활용 가능)
```
